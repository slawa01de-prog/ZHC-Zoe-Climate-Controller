# ZHC v4.8.3-alpha

**Status:** Alpha / Testing only

## Highlights

- Modusfarbe bleibt als Grundlicht sichtbar.
- Aktive Heizstufe wird mit hellen Impulsen angezeigt:
  - Stufe 0 = keine Impulse
  - Stufe 1 = 1 Impuls
  - Stufe 2 = 2 Impulse
  - Stufe 3 = 3 Impulse
- Zyklus ungefähr alle 4 Sekunden.
- OEM bleibt blau atmend.
- AUTO = grün.
- BOOST = orange.
- MANUAL = cyan.
- Fehler, Warnung, OTA und Service haben Vorrang.
- OEM-Sofortabschaltung und Service-Diagnose aus V4.8.2 bleiben enthalten.
