# ZHC v4.7-alpha

**Status:** Alpha / Testing only

## Highlights

- Vollständigeres Web-Dashboard
- Betriebsarten OEM / AUTO / BOOST / MANUAL im Browser
- Solltemperatur, Totband und Restart-Differenz im Web
- DS18B20-Rollenzuweisung und Sensor-Offsets im Web
- Regler-, Heizstufen- und Safety-Parameter im Web
- Lernsystem und Diagnose im Browser
- Konfigurations-Backup und Restore
- OTA-Firmwareupdate weiterhin integriert
- Terminal bleibt als Service-/Fallback-Ebene erhalten

## Sicherheit

H1/H2/H3 sind ausschließlich 3,3-V-Logik-/Bench-Ausgänge.
Keine direkte Verbindung zu Hochvolt-, PTC-Leistungs- oder HV-Schützpfaden.

Vor einem OTA-Update setzt die Firmware die eigene Regelung in einen sicheren Zustand:
OEM-Modus, H1/H2/H3 AUS und Reglerausgang 0 %.
